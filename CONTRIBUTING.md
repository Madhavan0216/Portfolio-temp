# Contributing

## Development

1. Fork the repository.
2. Create a focused feature branch.
3. Install dependencies with `npm install`.
4. Run `npm run dev` for local development.
5. Run `npm run build` before opening a pull request.

## Guidelines

- Keep changes scoped and well documented.
- Follow the existing TypeScript and React conventions.
- Do not commit generated build output, dependencies, secrets, or environment files.
- Use descriptive commit messages.
